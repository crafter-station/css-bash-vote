Project Notes

Discovery

Start by mapping the audience, the primary task, and the smallest useful version of the experience.

Implementation

Build the interaction around semantic HTML first, then layer on styling that keeps keyboard and screen-reader behavior intact.

For expanding panels, intrinsic sizing keeps each item matched to its real content instead of relying on guessed limits.

Review Checklist

Before shipping, verify the interaction with pointer, keyboard, and reduced-motion settings.

  • Headers remain clickable and focusable.
  • Each panel animates to its own natural height.
  • Content does not overlap during the transition.
